# rizkyantomalah.github.io

Personal academic portfolio for **Rizkyanto Malah**, built for GitHub Pages.

## Publish on GitHub Pages

1. Create a repository named exactly: `rizkyantomalah.github.io`
2. Upload:
   - `index.html`
   - `style.css`
   - `script.js`
3. Commit the files to the `main` branch.
4. Open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select `main` and `/ (root)`, then click **Save**.
7. Your site should be available at:
   `https://rizkyantomalah.github.io`

## Before publishing

Open `index.html` and replace:
- `YOUR_EMAIL@example.com`
- LinkedIn `href="#"`
- Google Scholar `href="#"`

You can later add a real profile photo by replacing the `.avatar` block with an `<img>` element.
