# Academic Profile V2

Replacement design for `rizkyantomalah.github.io`.

## Files to replace on GitHub
Upload/replace these files in the repository root:

- `index.html`
- `style.css`
- `script.js`

## Optional profile photo
Upload a photo named `profile.jpg`, then in `index.html` replace:

```html
<div class="photo-placeholder">RM</div>
```

with:

```html
<img src="profile.jpg" alt="Rizkyanto Malah" class="profile-photo">
```

Also replace the placeholder email, LinkedIn, and Google Scholar links.
